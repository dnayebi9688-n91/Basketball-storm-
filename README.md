# CourtSide | کورت‌ساید

وب‌سایت بسکتبال به نام دانیال نایبی. اجرای سایت فقط به Python 3.9+ نیاز دارد:

```bash
python3 server.py
```

سپس `http://localhost:8000` را باز کنید. در سرویس میزبانی، متغیر `PORT` به طور خودکار قابل تنظیم است. برای چت هوش مصنوعی، کلید OpenAI را فقط در متغیر محیطی سرور قرار دهید (هرگز در فایل‌های پروژه یا GitHub نگذارید):

```bash
export OPENAI_API_KEY='your-secret-key'
# اختیاری: export OPENAI_MODEL='gpt-4o-mini'
python3 server.py
```

## وضعیت داده‌ها
- بازی‌ها و جدول NBA، WNBA و بسکتبال دانشگاهی مردان NCAA از نقاط دسترسی غیررسمی ESPN دریافت می‌شوند؛ این سرویس ممکن است محدود شود یا تغییر کند. این پروژه وابسته یا مورد تأیید ESPN نیست.
- دریافت مجدد هر ۳۰ ثانیه انجام می‌شود؛ اطلاعات الزاماً ثانیه‌به‌ثانیه نیست و به تأخیر منبع وابسته است. ساعت روی صفحه هر ثانیه تغییر می‌کند. نبود مسابقه در یک روز طبیعی است.
- پوشش تمام لیگ‌های جهان در این نسخه پیاده‌سازی نشده است. برای آن باید یک تأمین‌کننده تجاری با پوشش و مجوز مناسب، کلید API و بودجه تهیه و به سرور متصل شود.
- گفتگو فقط با تنظیم کلید API کار می‌کند. دستیار به طور پیش‌فرض به داده‌های زنده دسترسی ندارد و ممکن است خطا کند.

## انتشار و GitHub
این پوشه را به یک مخزن GitHub منتقل کنید. چون نتایج و چت به `server.py` متکی‌اند، GitHub Pages به تنهایی کافی نیست؛ برنامه را روی هاست پایتون با فرمان `python3 server.py` مستقر و متغیرهای محیطی را در پنل هاست تنظیم کنید. برای استفاده عمومی، پیش از انتشار باید محدودیت نرخ، محافظت از API چت، پایش هزینه و مجوزهای منبع داده را اضافه کنید.

## ثبت در Google Search Console
ثبت واقعی نیازمند دامنه عمومی و دسترسی مالک به حساب گوگل است و خودکار انجام نشده است. پس از انتشار، در Search Console یک property از نوع Domain یا URL prefix بسازید و مالکیت را طبق دستور گوگل با DNS یا فایل HTML تأیید کنید؛ سپس نشانی صفحه را برای ایندکس ارسال کنید. بعد از تعیین دامنه، canonical، نشانی‌های Open Graph و sitemap.xml را با دامنه واقعی اضافه کنید. وجود meta description و robots.txt به تنهایی به معنی ثبت یا ایندکس شدن نیست.
